Expand your global market presence instantly

Creating and managing manual translations in Odoo can be slow and expensive. It requires installing language packs, manually translating every product description, blog post, and page, and keeping content synchronized. For businesses looking to scale quickly into new global markets, this operational overhead is a major bottleneck.

The Odoo Website Translator module provides an elegant solution. By overlaying a Google-powered translation widget onto Odoo’s frontend, it translates your entire website automatically and instantly into over 30 global languages. Visitors see your site in their own language without complex manual setups or high API translation fees.

To ensure a premium, native-feeling browsing experience, the module uses early head parsing scripts that check for active language preferences. This prevents the jarring "Flash of Untranslated Content" (FOUC), revealing the translated page only when it's fully ready.

Ideal Business Use Cases

  • International eCommerce: Localize product listings, checkout flows, and promo banners automatically to increase global sales.
  • Global Support Portals: Deliver documentation, FAQs, and contact forms in the customer's native language.
  • Multi-region Lead Generation: Enable local teams to present marketing copy and capture contact information in any region.
  • Low-Cost Market Testing: Test product-market fit in new countries instantly before investing in manual localization services.

Sleek Integration Details

The translator is built directly into Odoo's frontend assets without slowing down backend processing:

  • Asynchronous Loading: The Google Translate script starts downloading immediately during head parsing, minimizing blocking rendering.
  • Navigation Interceptors: Automatically intercepts click events on internal links to trigger transition overlays before opening new pages, keeping the layout clean.
  • Active Language Mapping: Queries active Odoo website languages, automatically mapping language codes and assigning flag emojis dynamically.

Backend Admin Controls

Manage the frontend experience directly inside the standard Odoo settings panel:

  • Language Selector: Restrict translation options by selecting specific active Odoo languages for the widget.
  • Flexible Positioning: Place the selector in the navbar header, as a floating button in the bottom corner, or both.
  • Interactive Layout Preview: Pick style shapes (Pill, Minimal, Flat) and test accent color themes directly in your configuration form.
  • Multi-website Settings: Fully compatible with Odoo's multi-website capabilities, allowing separate translation options and designs for different domains.

Quick Setup Guide

1. Install Addon

Add the Odoo Website Translator module to your custom Odoo addons directory and click install.

2. Open Settings

Go to Website settings and scroll down to the Google Translator Customizer section.

3. Style Widget

Select active languages, set layout (Pill/Minimal/Flat), and choose your brand's accent color.

4. Go Live

Save changes to display the custom widget immediately on your Odoo website frontend.
